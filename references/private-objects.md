# 天正、AEC 与其他自定义对象的只读识别

天正墙、门窗、房间等通常是应用自定义实体或对象，不应笼统当成普通 `INSERT` 块。目标是区分“文件声明了某类对象”“找到代理实例”“能看到几何”“能读取专业语义”四件事。

## 证据等级

1. **类登记证据**：DWG/DXF 的 CLASSES 区出现 `TCH_WALL`、`TCH_OPENING`、`TCH_SPACE`、AEC 类或对应应用名。只能证明文件声明或使用过这些类。
2. **实例证据**：读取到自定义实体、`ACAD_PROXY_ENTITY` 或 `ACAD_PROXY_OBJECT` 的实例、句柄、所有者和可用类标识。代理总数不能直接分配到各个专业类别。
3. **显示几何证据**：实例含 proxy graphics，或同版宿主/PDF 能显示其轮廓。显示几何可支持有限定位，但不等于读取了墙厚、门宿主墙、空间边界等内部参数。
4. **语义证据**：兼容的 Object Enabler、天正/AutoCAD 宿主 API 或该对象原生接口返回对象类型、参数和关联关系。只有这一层可称为已解码相应专业语义。

报告至少写明：`类登记：是/否/未知`、`代理实例：数量或未知`、`显示几何：可读/不可读/未检查`、`语义参数：可读/不可读/未检查`。未读到不等于不存在。

## 只读诊断顺序

1. 核验源文件哈希，读取版本、模型/布局、总实体数、图层、块、外参和图面范围。
2. 检查 CLASSES、应用注册名、自定义类型、代理实体/对象、XDATA 与扩展字典；记录句柄和所有者，不臆测类别映射。
3. 检查代理显示数据是否存在，并与可读原生线、弧、文字、块及同版 PDF/截图交叉核对。除非有句柄、容器或原生 API 关联证据，不把附近的原生几何自动归属于代理对象。
4. 若当前工具只看到代理壳，优先尝试已安装且版本兼容的 Object Enabler 或原生宿主只读接口。读取属性时记录宿主、插件和对象版本。
5. 仍不足时，在隔离副本上由兼容宿主导出为普通 CAD 图元；目标版本按现场安装能力选择，不固定为某个版本。不得覆盖原件或默认绑定外参。
6. 对转换前后比较图面范围、图层、文字、块、对象类别、外参状态和抽样几何。若关键对象丢失、偏移、文字变化或只有代理数归零，转换不能作为完整证据。

## 解析能力不足时的使用者选择

检测到自定义类或代理对象、且当前工具不能读取所需语义时，不自动安装软件，也不直接宣告任务失败。先报告检测证据、受影响的问题和当前仍可完成的范围，再提供与本题相关的选择：

1. **继续有限分析**：只使用已确认的原生几何、文字、块和视觉证据，并明确哪些结论无法覆盖自定义对象。
2. **启用已有解释器**：发现本机已有兼容 Object Enabler、天正或其他原生宿主时，先核对版本、位数、适用对象类型和只读能力，再询问是否用于该图纸。
3. **安装兼容解释器**：仅在有明确官方或可信来源、兼容版本和安装范围时提出。向使用者说明组件名称、来源、适配的 CAD/对象版本、是否需要管理员权限或重启、将修改的环境及预期增加的读取能力；取得明确选择后才安装。
4. **由使用者提供导出副本**：无法安全自动安装，或解释器依赖商业软件、许可、登录和交互安装时，请使用者从原生宿主导出普通 CAD 副本，并保留原图用于前后核验。

选择提示应包含“暂不安装/继续有限分析”，不能把安装当作继续任务的默认条件。若本题不依赖代理对象内部语义，不为追求形式上的完整而打断分析。若安装后仍无法解码，应保留原有限制，不重复安装相似组件。

推荐的提示信息：

> 检测到 `<类/代理对象及数量>`，当前读取器不能取得 `<受影响语义>`。现有对象仍可支持 `<可完成范围>`。请选择：继续有限分析；启用已发现的 `<解释器及版本>`；安装经核对兼容的 `<组件>`；或提供原生宿主导出的普通 CAD 副本。

## 可采用的读取方案

- **方案 A：代理显示几何**。成本低，可用于轮廓和位置复核；没有 proxy graphics 时不可用。
- **方案 B：Object Enabler / 原生宿主 API**。优先用于读取天正墙、门窗、房间等参数和关联，是语义识别的首选。
- **方案 C：兼容宿主转为普通图元**。适合后续几何与文字分析，但转换可能丢失参数化语义，必须保存转换报告并做前后核验。
- **方案 D：同版 PDF、截图或人工导出件交叉核对**。只能补足视觉证据；不得伪装成 CAD 对象级解码。

若只有类登记和不可解码代理对象，应表述为：“已确认文件含天正/自定义对象；当前数据不足，无法可靠判断这些对象的具体类型、参数或空间归属。” 已有独立的原生墙线、门弧和文字证据时，可以据此完成相应范围的空间关系分析，但要明确证据来自这些原生对象，而非代理对象内部语义。
