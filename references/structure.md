# 结构图读取与关系分析

适用：结构平面、基础、梁板柱墙、配筋、节点与剖面图的只读理解。不默认进行承载力、抗震、挠度、稳定或施工阶段安全验算。

## 建立本专业上下文

先读取图签、结构设计说明、图例及本图适用范围，区分基础/楼层/屋面、模板/配筋、结构布置/节点详图、既有/新增/拆除。材料、符号和构件命名按项目说明解释；说明缺失就标明。

读取轴号和交点、轴距、层号、标高基准、构件编号及截面文字。识别轴网断开、局部旋转和错层；不得以图面坐标相近替代同轴同层证据。

## 分对象读取

| 对象 | 优先提取 | 必须核对的关联 |
|---|---|---|
| 柱、墙 | 编号、轴位、截面、标高范围、配筋及变化处 | 平面位置与构件表、剖面/详图是否同一实例与楼层 |
| 梁 | 编号、跨段、截面、集中/局部标注、两端位置 | 每条标注适用哪一跨、哪一段；端部对应构件和节点证据 |
| 板 | 板区、厚度、标高、洞口、钢筋文字及引线 | 钢筋方向、层位、范围有无明确标注；板区是否跨越不同条件 |
| 基础 | 类型/编号、位置、尺寸、顶底标高、关联柱墙 | 基础表、剖面、承台/桩位等对应关系；不得按图形相似补数量 |
| 节点/详图 | 索引号、剖切方向、适用范围、连接与锚固标注 | 是否实际被主图引用、同版、同节点条件 |

保留配筋原始字符串、特殊符号和引线；字体/OCR 无法区分的钢筋符号、直径、数量、间距明确列疑点。未核清图例不能按习惯解释集中/原位标注的覆盖规则。

## 关系判断

分别记录四类事实，不互相替代：

1. **几何定位：**构件在某轴/某层/某范围，图面是否相交或相接。
2. **图示连接/支承：**编号、标高、剖面或节点支持何种连接/支承关系。
3. **力学解释：**只有图中相应证据明确时才描述传力关系；不能仅因梁线到柱边就断言刚接/铰接或完整传力机制。
4. **性能结论：**承载力足够、结构安全、可拆除等不能由图示连接直接推出。

双线交叉、梁跨过墙、上下层柱投影重合，只是候选关系。先排查不同标高、投影、洞口、断开符号和缺失详图。未读出板受力方向或边界条件，不按长短边自动推断。

节点没有直接文字时，可报告由明确几何与多张图共同支持的有限关系，并给推理链；不能机械地要求每个关系都有唯一标签，也不能省略矛盾信息。

## 输出

`构件A（轴位/层）｜连接或支承关系｜构件B｜平面/详图依据｜确认/未知/冲突`

具体构件属性另列：`编号｜位置｜图示尺寸/配筋原文｜适用范围｜依据`。

默认给结构对象概览、图间对应和缺失资料。用户问某构件如何连接时，只追踪相关节点和范围；问拆除/改造后果时，先指出图中可确认的关联和所缺计算输入，不输出凭外观得出的安全承诺。
